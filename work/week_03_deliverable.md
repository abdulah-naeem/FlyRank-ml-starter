## 3. The Identity Kit

### Typography Selection
* **Heading Font:** **Plus Jakarta Sans** (Clean, modern geometric sans-serif)
* **Body & Code Font:** **Inter** (Industrial-grade readability)

### Color Palette
| Role | Hex Code | Purpose & Usage |
| :--- | :--- | :--- |
| **Near-White Background** | `#F8FAFC` | Main viewport & canvas background |
| **Near-Black Text** | `#0F172A` | Primary typography & headers |
| **Main / Structural Color**| `#1E293B` | Navigation bars, primary buttons, borders |
| **Single Accent Color** | `#2563EB` | Interactive hover states, active links |

### Logo & Favicon Mark
- **Favicon (`favicon.svg`):** A high-precision monogram featuring **AN** set in **Plus Jakarta Sans** on a Deep Slate (`#1E293B`) rounded squircle with a Sapphire Blue accent dot (`#2563EB`).
- **Logo (`logo.svg`):** Clean typographic header brand combining the monogram mark with full name (Abdullah Naeem) and title.

### Two-Line Style Note
> Style Guide: Fonts: Plus Jakarta Sans (Headings), Inter (Body). Palette: #F8FAFC (Bg), #0F172A (Text), #1E293B (Primary), #2563EB (Accent).  
> Mood: Minimal, high-precision ML engineering notebook — calm slate & sapphire framing clean code, data contracts, and validation metrics without visual clutter.

### Discernment & Rejection Log (What Was Rejected & Why)

**❌ Rejected Option 1: Glowing 3D Cybernetic Neural Network Hero Graphic**
> *"While visually striking at first glance, it felt like generic AI stock art that competed with the actual work. It violated our calm slate design system (`#F8FAFC` / `#1E293B`) and gave the portfolio a hype-driven aesthetic rather than a disciplined, engineering-focused tone. Replaced with real metric indicators and clean code receipts."*

**❌ Rejected Option 2: Stylized Isometric Vector Illustration of a Developer at Desk**
> *"Generic vector illustrations fail to build personal trust with Senior ML Managers. It creates distance between the reader and the engineer. A real, unedited headshot photograph was chosen to establish authentic human credibility."*

**❌ Rejected Option 3: Synthetic Code Mockup Hero Card**
> *"Synthetic code mockups look fake under inspection. Real executed Jupyter Notebook cells and DuckDB query outputs provide authentic, verifiable proof without resorting to superficial visual fluff."*

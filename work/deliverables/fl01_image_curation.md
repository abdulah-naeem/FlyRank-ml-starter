## 2. Real Capture vs. AI Generation Decision Matrix

We strictly enforce three rules for image selection across the portfolio:

1. **Work & Code = 100% Real Captures:**
   - *Decision:* Screenshots of notebooks, DuckDB query outputs, sitemap sketches, and IDE windows are ALWAYS real unedited captures.
   - *Reference Projects:* Real project builds (`SurveilX`, `Crisis Simulator`, `CareerAgent AI`, `VeriVision`, `AcoustiAge`, `FlyRank SEO Engine`).
   - *Rationale:* Generated AI code mockups look artificial under scrutiny and destroy technical credibility. Senior ML Engineering Managers look for real code receipts, not stylized representations.

2. **Personal Identity = Real Photograph Only:**
   - *Decision:* A real professional headshot ([`work/assets/profile_headshot.png`](file:///d:/Internships/Internship%20-%20FlyrankAI/Week%201/FlyRank-ml-starter/work/assets/profile_headshot.png)) is used for Abdullah Naeem (BS AI, FAST NUCES Islamabad).
   - *Rationale:* AI avatars or stylized digital portraits create friction and reduce trust. Authentic human connection is required to drive "The One Action" (scheduling a technical interview).

3. **Connective Tissue = Strictly Styled Brand Assets:**
   - *Decision:* Generated visuals are restricted exclusively to minimal design system tokens (logo, favicon, swatch card) adhering strictly to our 4-color palette (`#F8FAFC`, `#0F172A`, `#1E293B`, `#2563EB`).
   - *Rationale:* Keeps the interface visual frame quiet and disciplined so that real case study code and math remain the loudest elements on the page.

## 3. Discernment & Rejection Log (What Was Rejected & Why)

### ❌ Rejected Option 1: Glowing 3D Cybernetic Neural Network Hero Graphic
* **What was generated:** A flashy 3D glass sphere with glowing neon neural node connections and floating futuristic data streams.
* **Why it was REJECTED:** 
  > *"While visually striking at first glance, it felt like generic AI stock art that competed with the actual work. It violated our calm slate design system (`#F8FAFC` / `#1E293B`) and gave the portfolio a hype-driven aesthetic rather than a disciplined, engineering-focused tone. Replaced with real metric indicators and clean code receipts."*

### ❌ Rejected Option 2: Stylized Isometric Vector Illustration of a Developer at Desk
* **What was generated:** An isometric cartoon illustration of a developer working at a multi-monitor desk with code windows and plants.
* **Why it was REJECTED:** 
  > *"Generic vector illustrations fail to build personal trust with Senior ML Managers. It creates distance between the reader and the engineer. A real, unedited headshot photograph was chosen to establish authentic human credibility."*

### ❌ Rejected Option 3: Synthetic Code Mockup Hero Card
* **What was generated:** A dark-mode synth-wave IDE mockup displaying fake stylized Python code lines with glowing syntax highlights.
* **Why it was REJECTED:** 
  > *"Synthetic code mockups look fake under inspection. Real executed Jupyter Notebook cells (`w03_data_contract.ipynb`) and DuckDB query outputs provide authentic, verifiable proof without resorting to superficial visual fluff."*
